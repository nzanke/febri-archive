# Febri 記事アーカイブ索引

2026年11月25日に閉鎖されるアニメ情報サイト Febri（febri.jp）の記事を、インターネットアーカイブ（Wayback Machine）の保存ページへのリンクとあわせてまとめた索引です。タイトル・著者名で検索できます。連載「ガールズ＆パンツァー 最終章 エンサイクロペディア」の用語は別ページ（gppedia.html）に五十音順でまとめています。

- `index.html` … 検索ページ
- `data.js` … 記事一覧（タイトル・日付・分類・著者・アーカイブURL）
- `gppedia.html` / `gppedia.js` … ガルパン用語辞典の一覧
- `build_index.py` … 一覧の作成スクリプト
